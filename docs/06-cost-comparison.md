# Cost Comparison

Local AI and cloud AI cost money in different ways. This section breaks both
down with real-world examples so you can decide what fits your budget.

## Local AI costs

| Cost | What it is | Typical price |
|------|------------|---------------|
| Software | Ollama, LM Studio | Free |
| Models | Downloads from public libraries | Free |
| Electricity | Running your computer | A few cents per session |
| Hardware | Computer you already own | $0 if you have one; otherwise the cost of the machine |

**Bottom line:** after you have a computer, local AI costs essentially nothing
to run — no subscription, no per-message fee, no API key.

The one hidden cost is hardware: if your computer can't run the model you
want, you may need more RAM or a better graphics card. But you can always run
a smaller model on what you have.

## Cloud AI costs

| Cost | What it is | Typical price |
|------|------------|---------------|
| Subscription | Chatbot Plus/Pro plans | ~$20/month |
| API usage | Pay per 1,000 words (tokens) | Varies; a few dollars can go far |
| Account | Often required | Free to sign up, paid to use heavily |

Cloud AI is cheap for light use and can add up if you use it heavily every
day. A casual user might spend $0–$20/month; a power user can spend much more.

## Real-world examples

**Scenario A: occasional writer**
You want help drafting emails and blog posts a few times a week.
- Local: free. Download a 7B model, run it on your laptop.
- Cloud: free tier may cover it, or ~$0–$20/month for a subscription.
- **Winner:** local (free, private, no account).

**Scenario B: small business owner**
You want to analyze customer feedback and write proposals daily.
- Local: free on an 8–16 GB laptop with an 8B model.
- Cloud: ~$20/month subscription plus possible API fees for volume.
- **Winner:** local for everyday work; cloud occasionally for harder tasks.

**Scenario C: complex coding or research**
You need a very large model for hard reasoning once in a while.
- Local: may not run well on your hardware; buying a GPU is expensive.
- Cloud: pay only for the hours or tokens you use.
- **Winner:** cloud for the occasional heavy job, local for daily work.

## The hybrid approach (recommended)

Use local AI for daily, private, repetitive tasks. Use cloud AI occasionally
for harder reasoning or when you're away from your computer. You get privacy
and low cost most of the time, with power when you need it.
