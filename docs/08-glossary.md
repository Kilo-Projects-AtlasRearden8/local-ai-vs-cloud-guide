# Glossary

Plain-English definitions for terms used in this manual.

**API key** — a secret code that lets a program talk to an online service. You
don't need one for local AI.

**Cloud** — someone else's computers, accessed over the internet.

**Context** — the text (prompt plus earlier messages) the model considers when
answering. Longer context uses more memory.

**GGUF** — a file format for AI models that runs well on consumer hardware.
Used by Ollama and LM Studio.

**Instruct / chat model** — a model trained to follow instructions and hold a
conversation, as opposed to a raw "base" model that just completes text.

**LLM** — large language model. An AI trained on lots of text that can write,
summarize, code, and chat.

**Local** — running on your own computer, with nothing sent over the internet
to use the model.

**Parameter** — one of the billions of adjustable values inside a trained
model. More parameters usually mean a smarter but bigger model.

**Quantization** — compressing a model to a smaller file (Q4, Q5, Q6, etc.)
with a small trade-off in quality.

**RAM** — your computer's main working memory.

**VRAM** — memory on a graphics card, used to run AI models faster.

**Token** — a chunk of text (part of a word) that models read and write.
Roughly 1,000 tokens ≈ 750 words.
