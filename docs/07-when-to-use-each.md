# When to Use Each

You don't have to pick one forever. Most people use both. Here is a simple
guide to help you choose in the moment.

## Use local AI (Ollama or LM Studio) when

- Privacy matters: personal notes, client information, business drafts
- You don't want an account, API key, or subscription
- You're offline or on spotty internet
- You're doing everyday tasks: rewriting, summarizing, simple Q&A, drafting
- You want to practice and learn without paying
- You're running repeated tasks on the same computer

## Use cloud AI when

- You need a very large model your computer can't run
- You're away from your computer and only have a phone
- You need web browsing built into the answer
- You're doing occasional hard reasoning or complex coding
- You're collaborating with others through a shared cloud workspace

## Quick decision flowchart

```
Do you need this answer private or sensitive?
├── Yes → Use local AI
└── No → Continue

Is your computer able to run a 7B–8B model comfortably?
├── Yes → Try local first
└── No → Use cloud or upgrade later

Is the task very hard (complex code, deep research)?
├── Yes → Consider cloud for this one task
└── No → Use local AI
```

## Suggested starter routine

1. **Every day:** local AI for emails, drafting, summaries, learning.
2. **Once in a while:** cloud AI for a hard problem your local model can't
   handle.
3. **Always:** keep sensitive text local.

Both tools are free to try. Start local, add cloud only when you need it.
