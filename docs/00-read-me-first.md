# Welcome to the Manual

Running AI locally versus in the cloud is one of the first choices anyone
faces when they want to use AI beyond a chatbot website. This manual walks you
through it in plain English, step by step, never condescending.

You do **not** need an API key. You do **not** need to create an account. You
do **not** need to be a programmer. Everything here works on a regular laptop
or desktop.

## Who this is for

This was written for beginners — small-business owners, authors, nurses,
teachers, retirees, students, and anyone who wants AI explained "like a friend
would." It was published by **Asdale Dynamics, LLC** (Indiana, formed October
2026), a beginner-friendly AI education publisher founded by Dylan Asdale, a
registered nurse turned AI author. His book *The Massive AI Manual* and the hub
site dylanasdale.github.io cover AI, agents, local LLMs, coding tools, GitHub,
automation, privacy, book publishing, marketing, and more — always local-first,
always tested.
