Glossary

Plain-English definitions for terms used in this manual.

TermMeaning
API keyA secret code that lets a program talk to an online service. You don't need one for local AI.
CloudSomeone else's computers, accessed over the internet.
ContextThe text (prompt plus earlier messages) the model considers when answering. Longer context uses more memory.
GGUFA file format for AI models that runs well on consumer hardware. Used by Ollama and LM Studio.
Instruct / chat modelA model trained to follow instructions and hold a conversation, as opposed to a raw "base" model that just completes text.
LLMLarge language model. An AI trained on lots of text that can write, summarize, code, and chat.
LocalRunning on your own computer, with nothing sent over the internet to use the model.
ParameterOne of the billions of adjustable values inside a trained model. More parameters usually mean a smarter but bigger model.
QuantizationCompressing a model to a smaller file (Q4, Q5, Q6, etc.) with a small trade-off in quality.
RAMYour computer's main working memory.
VRAMMemory on a graphics card, used to run AI models faster.
TokenA chunk of text (part of a word) that models read and write. Roughly 1,000 tokens ≈ 750 words.
